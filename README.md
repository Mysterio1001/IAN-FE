# ian-fe｜Ian 前端開發 Skill

**版本：1.2.1**

將設計圖或需求轉成符合 Ian 慣例的 iMES 前端程式碼，適用於使用 Vue 2 與 Element UI 的目標專案。安裝只需一個 `SKILL.md`，不需要參考專案的業務程式碼。

## 讓 agent 幫你安裝

先用 coding agent 開啟**要開發的目標專案**，將本 skill 的 `SKILL.md` 附給它（或提供它可讀取的來源路徑），然後貼上這段：

```text
請將我提供的 ian-fe skill 安裝到目前專案，
```

## 如何叫用

| 工具 | 在目標專案的對話中輸入 |
| --- | --- |
| Codex | `$ian-fe 依照附圖建立唯讀查詢頁，API URL 尚未提供。` |
| Claude Code | `/ian-fe 依照附圖建立唯讀查詢頁，API URL 尚未提供。` |
| Cline | `請使用 ian-fe skill，依照附圖建立唯讀查詢頁，API URL 尚未提供。` |

若目前對話未發現新 skill，先在同一專案開新對話。

直接描述需求，不必指定模式。調整既有按鈕或欄位等「微調」只驗證受影響的行為；新建頁面、整頁改版或跨元件串接新流程，則走「新建或編輯完整頁面」流程。兩者遵守相同的寫入範圍與模板規則。

## 版本更新歷史

### 1.2.1

- 微調與完整頁面皆預設不新增布林變數：優先使用既有模式與狀態，不另存可推導的旗標；僅保留獨立狀態或模板要求的旗標。

- 彈窗可編輯表單與列表列資料隔離；取消不影響列表。補充完整 CRUD 的方法排列偏好、報表動態欄位及作業站掃碼焦點慣例，微調流程不變。

- 新增權限模板：在 `created()` 從 `permissions` 讀取對應權限，按鈕的 `v-if` 直接使用同名欄位。
- 每處 i18n 用法都要就近加繁體中文註解，包含模板、腳本與 `init.js` 的語系鍵。

### 1.2.0

- 入口依需求分流：微調不啟動子代理或整頁檢查；新建與整頁編輯保留完整規劃及整合驗證。
- 新增 `init.js`、`ui/search-ui.vue` 與五種主檔操作按鈕模板。按鈕權限直接寫在 `el-button`；元件不增加模板外的參數。
- 選擇窗一律排在根節點最前；單一主彈窗直接引用 main，不另取業務別名。Vue 單檔元件除 import 外不在 `export default` 外宣告函式或變數。
- 保留既有 API 檔名與匯出介面，新增或修改的 API 一律依固定模板。缺 URL 的操作在頁面方法以註解與 `return` 暫停，不加提示元件。

### 1.1.0

- 新增可寫入檔案白名單：主代理、子代理與驗證修正皆限於本次頁面模組及專用 API；修改 Axios 等共用程式須先取得明確授權。
- 統一 API 函式版型：僅引用 `request` 與必要的服務前綴，直接 `return request({...})`。缺 URL 時保留 `// IAN TO DO`，由頁面暫不呼叫。
- 加入去識別化的主檔、報表與作業站布局範例。預設不新增自訂 class；必要時使用小駝峰，如 `resultViewport`。

### 1.0.0

- 首版提供 Ian 風格的 Vue 2／Element UI 前端生成規則、六步開發流程與單檔 skill 安裝包。
